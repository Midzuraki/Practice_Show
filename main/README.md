# Папка main

## main.py

`main.py` — точка входа CapyCafe. Файл отвечает за:

- определение пути к базе данных при запуске из Python и из собранного приложения;
- проверку и первоначальное создание базы, если обязательные таблицы отсутствуют;
- выбор профиля сотрудника по ID;
- отображение меню, доступного выбранной роли;
- ввод данных и форматированный вывод блюд, сотрудников, заказов и отчётов;
- передачу операций соответствующим модулям из `database/scripts/`.

Запуск из корневой папки проекта:

```bash
python -m main.main
```

Приложение использует консольный интерфейс. Вход по ID является учебным механизмом выбора роли и не заменяет полноценную аутентификацию.
