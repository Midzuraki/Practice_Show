# Папка database

В этой папке находятся SQL-файлы и Python-модули, работающие с SQLite.

## Основные файлы

- `schema.sql` — создание структуры таблиц.
- `data.sql` — демонстрационные записи.
- `scripts/createdb/` — вспомогательные сценарии инициализации базы.

## Модули scripts

- `authorization/` — выбор сотрудника и управление профилями.
- `dishes/` — блюда, категории, поиск и просмотр данных таблиц.
- `orders/` — оформление заказов, состав, суммы, статусы и отмена.
- `reports/` — запросы для рейтинга блюд, выручки, эффективности официантов и отменённых заказов.
- `test/` — основной набор модульных тестов.

База приложения хранится локально в `database/capycafe.db`. Файл создаётся при первом запуске и не должен добавляться в Git. Цена каждой позиции заказа сохраняется отдельно, чтобы изменения меню не переписывали историю.
